# Online-Gaming-DBMS
End-to-end relational database solution (3NF) for an online gaming platform. Built with SQL Server, complex queries, ERD modeling &amp; data integrity rules.
# Online Gaming Database Management System (DBMS)

## 📌 Overview
The project focuses on data architecture, scalability, integrity, and query performance optimization.

Designed as part of the **BI Developer Training Program** at **Upscale Analytics**.

---

##  Key Architecture & Features
* **Database Architecture & Normalization:** Designed a scalable relational schema up to Third Normal Form (3NF) to minimize redundancy and maintain strict data integrity.
* **ERD & Entity Design:** Engineered Entity-Relationship Diagrams (ERD) featuring Fact tables, Dimension/Lookup tables, and Junction tables for managing complex many-to-many relationships.
* **Data Integrity & Business Logic:** Enforced strict relational integrity using Foreign Keys, Unique constraints, and Data Validation rules.
* **Complex SQL Queries & Performance Optimization:** Wrote optimized SQL queries, stored procedures, and views for real-time reporting, engagement tracking, and analytical metrics.

---

##  Tech Stack & Tools
* **Database Engine:** SQL Server / Relational DBMS
* **Languages & Scripting:** SQL (DDL, DML, Advanced Queries)
* **Data Modeling:** ERD Modeling, 3NF Normalization
* **BI & Analytics:** Business Analytics, Tableau / Data Visualization
